# results/

Raw data and recomputed statistics behind every table and figure in
*Tune the Baseline First: Most of Muon's Scaled Weight Decay Gain Is a Tuning Gap,
but Its Small Real Advantage Grows With Model Size*.

Generated by `export_results.py` on 2026-11-02 from 81 finished runs (git commit `n/a`).
All BPB values are held-out bits per byte (lower is better). Verification against the paper: **ALL CHECKS PASS**
(see `checks.csv`).

| File | Contents | Supports |
|---|---|---|
| `runs.csv` | One row per run: name, rung `L`, TPP, schedule, method, LR / LR*WD multipliers, seed, status, final BPB (pooled and per source), loss, tokens, FLOPs, wall time, segments (pre-emption resumes), device, throughput | everything |
| `sweeps_1d.csv` | Mean final BPB per (rung, method, LR*WD multiplier `p`) at LR multiplier 1, cosine, TPP 120 | Fig. 1 |
| `main_results.csv` / `.json` | Per rung: untuned gap (at p=1), tuned gap (quadratic fit in log2 p), surviving share, fitted optima, WD ratio, edge flags; plus fit coefficients | Table 1 (upper), Figs. 2-3 |
| `l3_tuned_seeds.csv`, `l3_paired_seeds.json` | L3 runs at the 2D-fitted optima, four paired seeds; per-seed gap, mean, SD, t-based 95% CI | Table 1 (lower), Fig. 4 |
| `l3_untuned_seeds.json` | L3 gate-1 pairs at the MAI-law setting (p=1) | Gate 1, untuned gain |
| `eval_curves.csv` | Held-out BPB during training for every run (from `evals.jsonl`) | trajectory claims |
| `benchmarks.csv` | Measured CPU vs T4 throughput per rung | Sec. 3.6, Table 3 |
| `analysis/` | Copy of `analysis.py` output: `results.json`, `fits.json` (2D L3 fit, WD-ratio bootstrap, WSD, L6 transfer), `report.md`, figures, LLM reviews | Table 2, Table 4, hypothesis tests |
| `runs/<run>/` | Per-run `summary.json`, `config.json`, `evals.jsonl` (checkpoints excluded) | raw evidence |
| `environment.json` | Python/package versions, ladder, data sources, MAI laws, preregistered thresholds (no Azure settings or secrets) | reproducibility |
| `checks.csv` | Every paper number recomputed from the raw runs, with tolerance and PASS/FAIL | verification |
| `MANIFEST.json` | SHA-256 and size of every file in this folder | integrity |

## Definitions
- **Untuned gap**: BPB(constant WD) - BPB(Muon-SW), both at the MAI-law setting (p = 1).
- **Tuned gap**: same difference after each method is tuned over p (quadratic in log2 p; if the fitted
  optimum lies outside the sweep, the better of fitted and best observed BPB is used).
- **Surviving share** = tuned gap / untuned gap.  **WD ratio** = p*(Muon-SW) / p*(constant).
- L3 four-seed CI: paired differences over seeds 1-4, mean +/- t(0.975, n-1) * SD / sqrt(n).
